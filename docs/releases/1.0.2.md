# Diet Copilot Web 1.0.2 / Android 7.0.3

This maintenance release repairs the Google OAuth handoff for both the browser dashboard and Android companion.

## Authentication

- Web and Android OAuth attempts identify their intended return client explicitly before leaving for Google.
- The exact Supabase PKCE `flowId` is preserved through the shared WORDSTRIKE Site URL relay and used during code exchange.
- Web callbacks return to `/diet/`; Android callbacks return through `/diet/native-auth-callback.html` and `dev.thiepn.diet://auth-callback/`.
- Android starts external authentication through `/diet/native-auth-start.html`, which establishes the native relay marker in the external browser before forwarding to Supabase.
- OAuth relay markers are one-shot and removed after callback routing.
- Auth bootstrap/callback pages bypass the Diet service-worker app shell.

## Release

- Stable web release: `1.0.2`
- Android companion: `7.0.3`
- No nutrition, coaching, history, trends, insights, or backend data-model behavior changed.
