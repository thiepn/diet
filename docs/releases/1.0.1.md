# Diet Copilot Web 1.0.1 / Android 7.0.2

Release channel: **stable**  
Date: **2026-09-16**

## Purpose

This maintenance release closes the authentication and Android packaging gaps found after Web 1.0.0. It does not add a new nutrition workflow.

## Web

- Google-only THIEPN Account UI
- Supabase PKCE authentication
- password-auth code removed from all active runtime layers
- asset/cache generation rotated to `1.0.1`
- pinch-to-zoom restored
- native callback page included in release certification

## Android

- companion version `7.0.2` / versionCode `702`
- PKCE OAuth returns through `dev.thiepn.diet://auth-callback/`
- non-debuggable release manifest
- Android backup disabled
- cleartext traffic disabled
- v2/v3 APK signature verification
- no unrelated camera, location or legacy storage permissions

## Backend

The canonical project remains `hycegznamzjhwinegaai`. Browser Diet tables remain authenticated SELECT-only and owner-scoped. Final integrity checks found no duplicate day/weight rows, owner mismatches, negative nutrition values, or meal/item aggregate mismatches.

The finalization migration also optimizes the native-device owner policy to cache `auth.uid()` once per query and adds a covering index for `saved_food_portions.saved_food_id`.
