# Diet Copilot 2.0.3

**Product certification:** P38 — Product Release Candidate  
**Channel:** Stable production  
**Runtime:** P37 frozen product runtime

Diet Copilot 2.0.3 is the stable production release certified at the end of the P27–P38 product track.

## Product surface

The release includes:

- fast food capture and reusable food/meal memory;
- onboarding, goals and phase setup;
- adaptive weekly strategy review;
- Copilot-assisted actions with explicit local authorization;
- progress, trend and adherence analytics;
- mobile/PWA interaction hardening;
- visual motion with reduced-motion support;
- THIEPN Account and Hub integration;
- long-session, offline, owner-transition and uncertain-write hardening.

## Release certification

P38 freezes the P37 runtime and adds release-only certification.

No nutrition logic, database schema, product UI or runtime bundle is changed by P38.

The release is validated by static contracts, exact public asset matching, three-browser production checks, the Account/operations contracts, and the existing production security/recovery stack.

## Maintenance

After P38, development defaults to defect-only maintenance. New feature work requires an explicit new product requirement rather than extending the completed roadmap automatically.
