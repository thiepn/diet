# Diet Copilot Web 1.0.0

Internal milestone: **V6.8**  
Release channel: **stable**  
Date: **2026-09-14**

## Summary

Web 1.0.0 promotes the V6.7 release candidate to the stable Diet Copilot web baseline. It intentionally adds no new logging workflow. The release focuses on source cleanup, production certification, deployment reliability and preserving the conversation-first product boundary.

## Source cleanup

- active runtime source moved under `src/`
- auth, core, UI, intelligence, operations and styles are separated by responsibility
- historical root-level dashboard fragments were removed from the active tree
- retired fragments, the V6.7 build script and V6.7 tests were moved to `archive/`
- archived files are excluded from the production builder and GitHub Pages output

## Stable runtime

- internal version: `6.8`
- web release: `1.0.0`
- release channel: `stable`
- service-worker cache: `diet-copilot-web-v1.0.0`
- exactly one local JS bundle: `diet-app.js`
- exactly one local stylesheet: `diet.css`

The `window.DietRelease` diagnostic surface certifies the final Today invariants, read-only product boundary, horizontal-overflow state and Realtime-channel count.

## Permanent product invariants

- ChatGPT is the food/weight logging entry point
- dashboard remains read-only
- no Quick Capture
- no manual food-entry forms
- no close-day requirement for metrics
- all logged intake counts
- missing fiber remains unknown
- uncertainty changes confidence rather than whether intake counts
- activity calories are not automatically eaten back
- target recommendations require explicit approval
