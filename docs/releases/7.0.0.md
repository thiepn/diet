# Diet Copilot V7.0 — Android Companion

V7.0 extends the stable Diet Copilot Web 1.0 product with a native Android shell. The web product remains the primary read-only dashboard and ChatGPT remains the nutrition logging/control layer.

## Included

- Capacitor 8 Android project generation
- Android app ID `dev.thiepn.diet`
- Health Connect read integration for steps, active calories, distance and exercise sessions
- Android Keystore-encrypted Supabase session handoff for background work
- foreground Health Connect sync
- WorkManager background activity sync
- native weigh-in and weekly-review notifications
- Android-only Health Connect status card in Account
- existing Web 1.0 UI, data model, intelligence and THIEPN Account
- Android CI that builds and uploads a debug APK

## Explicitly unchanged

- no manual nutrition entry on the dashboard
- no Android-specific meal logger
- no Quick Capture
- no activity-calorie eat-back
- no separate backend or account system
- no sleep, hydration or workout-programming scope

## Certification levels

### Automated

- Web 1.0 regression suite
- V7 product/backend contract
- generated Android project compilation
- debug APK generation

### Requires a real device

- Health Connect permission flow
- actual Health Connect data reads
- background-read behavior under OEM battery management
- notifications on the target phone
- installed-app lifecycle/resume behavior

### Requires release credentials

- signed release AAB/APK
- Play Console upload and production signing

The debug build is useful for direct device testing, but is not a Play Store production release.
