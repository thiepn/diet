# Legacy archive

This directory contains Diet Copilot implementation history that is no longer part of the active Web 1.0 source tree.

- `legacy-dashboard/` — superseded dashboard/runtime fragments
- `legacy-build/` — superseded release-candidate build tooling
- `legacy-tests/` — superseded release-candidate tests

Nothing under `archive/` may be included by `scripts/build-v68.mjs`, `diet-app.js`, or `diet.css`. The archive exists only for development history and migration reference and is excluded from the GitHub Pages production output.
